Part 1 — The Basics

An API is a set of addresses on a server. Your app sends a request and the server returns a response (JSON). Think of it like a waiter: you order, the waiter brings the result.

Key words

WordMeaning
Base URLThe server address. Every endpoint starts with it.
EndpointA specific address + action, e.g. POST /api/events/public/SKJ26V/register
GETFetch / read something. No body.
POSTCreate something new (registration, photo upload).
PUTUpdate something.
Request bodyThe JSON data sent with POST/PUT.
ResponseThe JSON returned by the server.
JSONText data as "key": "value" pairs.
Status code200 ok · 201 created · 400 bad request · 404 not found · 409 already exists · 500 server error
Event IDShort uppercase code for an event (e.g. SKJ26V) that goes in URLs — not the DB _id.
PhoneThe volunteer's identity. Always exactly 10 digits.

Base URL

EnvironmentBase URL
Productionhttps://vcc-client.vercel.app
Local devhttp://localhost:3000

What is curl?

curl is a command-line tool (built into Windows 10/11, macOS, Linux) to test API calls. On Windows open Command Prompt and type the command. Example:

curl https://vcc-client.vercel.app/api/health

Authentication

All mobile endpoints are public — no login. Admin endpoints need a JWT token sent as a header: Authorization: Bearer <token>. The mobile app never needs this.

Part 2 — Mobile Endpoints (8 calls your app needs)

1. Check the server is alive

GET /api/health

curl https://vcc-client.vercel.app/api/health
{ "status": "ok", "timestamp": "2026-08-10T05:49:57.101Z", "mongodb": "connected" }

2. Get the list of events

GET /api/events/public

Returns events that are registration_open, registration_closed, or ongoing.

curl https://vcc-client.vercel.app/api/events/public
{
  "events": [
    {
      "_id": "6a7717364ae497f56781ce9b",
      "eventId": "SKJ26V",
      "name": "Sri Krishna Janmashtami 2026",
      "venue": "Gadiraju convention centre",
      "registrationEnd": "2026-08-21T04:16:00.000Z",
      "eventStart": "2026-09-04T04:16:00.000Z",
      "eventEnd": "2026-09-08T04:16:00.000Z",
      "status": "registration_open",
      "photoRequired": false,
      "coordinatorId": { "name": "chaitanya", "email": "..." }
    }
  ]
}

Show events with status: "registration_open" as "Register now". Use eventId (e.g. SKJ26V) in the URLs for steps 3, 4 and 6. If photoRequired is true, require a photo (step 5).

3. Get event details (registration form)

GET /api/events/public/:eventId

Returns the full event, including availabilitySlots, photoRequired, and customFields.

curl https://vcc-client.vercel.app/api/events/public/SKJ26V
{
  "event": {
    "eventId": "SKJ26V",
    "name": "Sri Krishna Janmashtami 2026",
    "photoRequired": true,
    "availabilitySlots": ["Morning 8-11 AM", "Evening 5-8 PM"],
    "customFields": [
      { "id": "a1b2c3", "label": "Vehicle number", "type": "short_text", "required": false },
      { "id": "d4e5f6", "label": "Preferred department", "type": "select", "required": true, "options": ["Parking", "Prasadam", "Security"] }
    ]
  }
}

Custom field types: short_text, long_text, number, email, phone, select, radio, checkbox, date, devotee_select. 404 → { "message": "Event not found" }

4. Get event time slots

GET /api/events/public/:eventId/time-slots

curl https://vcc-client.vercel.app/api/events/public/SKJ26V/time-slots
{ "eventId": "SKJ26V", "name": "...", "eventStart": "...", "eventEnd": "...", "timeSlots": ["Morning 8-11 AM", "Evening 5-8 PM"] }

Send the volunteer's chosen slots back in registration as serviceAvailability: [{ "date": "2026-09-04", "timeSlot": "Morning 8-11 AM" }]

5. Upload a volunteer photo (optional)

POST /api/upload/photo

Send multipart/form-data with the JPEG in the field photo (under 1 MB — compress in the app). Returns a key to pass as photoKey in registration. Required only when the event has photoRequired: true.

curl -X POST https://vcc-client.vercel.app/api/upload/photo ^
  -F "photo=@C:\photos\rama.jpg"

201 → { "key": "volunteers/1725182601234-ab12cd.jpg" }
400 → No photo provided or Photo exceeds 1 MB limit after compression

Serving the photo: GET /api/upload/photo?key=volunteers/xxx.jpg → 302 redirect to a pre-signed URL (1 h), cached for a year.

6. Register a volunteer

POST /api/events/public/:eventId/register  — most important endpoint

Looks up the volunteer by phone (reuses their profile if they've volunteered before, otherwise creates one), then creates the registration for the event.

{
  "name": "Rama Das",
  "phone": "9876543210",
  "age": 28,
  "gender": "male",
  "locality": "Dwaraka Nagar",
  "occupation": "Software Engineer",
  "occupationType": "working",
  "company": "ACME Ltd",
  "skills": ["it", "photography"],
  "photoKey": "volunteers/1725182601234-ab12cd.jpg",
  "serviceAvailability": [{ "date": "2026-09-04", "timeSlot": "Morning 8-11 AM" }],
  "customAnswers": [{ "fieldId": "d4e5f6", "value": "Parking" }]
}

Required: name, phone. Phone is normalized to the last 10 digits. Skills: medical, photography, videography, driving, electrical, sound, it, graphic_design, cooking, crowd_management, other. customAnswers can be an array of {fieldId, value} or an object map; required custom fields are enforced server-side.

curl -X POST https://vcc-client.vercel.app/api/events/public/SKJ26V/register ^
  -H "Content-Type: application/json" ^
  -d "{\"name\":\"Rama Das\",\"phone\":\"9876543210\"}"
{
  "message": "Registration successful",
  "registration": { "_id": "...", "eventId": "...", "volunteerId": "...", "status": "registered" },
  "volunteer": { "_id": "...", "name": "Rama Das", "phone": "9876543210", "photoKey": "volunteers/1725182601234-ab12cd.jpg" }
}
StatusMessageApp should show
400Registration is not open for this eventEvent not accepting registrations
400Registration deadline has passedToo late
400Phone number must be exactly 10 digitsFix phone input
404Event not foundWrong event code
409Already registered for this event"You're already registered"

Alternative: POST /api/registrations does the same but takes the Mongo _id as eventId in the body. Prefer the URL form above.

7. Venue check-in (QR code at the event)

POST /api/events/public/:eventId/check-in

Print a QR at the venue that opens /check-in/:eventId. The volunteer types their registered phone number and attendance is confirmed in one step. Any registered volunteer can check in — the admin sees who's present and assigns seva on the spot.

curl -X POST https://vcc-client.vercel.app/api/events/public/SKJ26V/check-in ^
  -H "Content-Type: application/json" ^
  -d "{\"phone\":\"9876543210\"}"
{
  "message": "Check-in successful",
  "alreadyCheckedIn": false,
  "volunteer": { "_id": "...", "name": "Rama Das", "phone": "9876543210", "photoKey": "volunteers/...jpg" },
  "event": { "_id": "...", "name": "Sri Krishna Janmashtami 2026", "venue": "Gadiraju convention centre" },
  "registration": { "_id": "...", "status": "attended", "serviceId": null }
}

alreadyCheckedIn: true means they had already checked in (idempotent). serviceId is their assigned seva, if any.

StatusMessageApp should show
400Phone number must be exactly 10 digitsFix phone input
400You have been marked as a no showCannot check in
404Event not foundWrong QR / link
404You are not registered as a volunteer"Not registered"
404You are not registered for this event"Not registered for this event"

8. Show a volunteer's seva ("My Seva")

GET /api/volunteers/by-phone/:phone

Returns the volunteer's profile + all registrations with event, assigned service, and coordinator contact. Use it for both the pre-registration check and the "My Seva" screen.

curl https://vcc-client.vercel.app/api/volunteers/by-phone/9876543210
{
  "volunteer": { "_id": "...", "name": "Rama Das", "phone": "9876543210", "photoKey": "volunteers/1725182601234-ab12cd.jpg" },
  "registrations": [
    {
      "_id": "...",
      "status": "assigned",
      "eventId": { "name": "Sri Krishna Janmashtami 2026", "eventId": "SKJ26V", "venue": "...", "status": "registration_open" },
      "serviceId": {
        "name": "Parking",
        "coordinatorId": { "name": "chaitanya", "phone": "..." }
      }
    }
  ]
}

When admin assigns work, serviceId becomes populated. photoKey (if present) lets the app show the volunteer's photo via GET /api/upload/photo?key=. 404 → { "message": "Volunteer not found" }

Note — Status changes are admin-only

Volunteers can never change their own status — the app only reads seva data. All status transitions happen in the admin panel via PUT /api/registrations/:id/status.

Part 6 — How Volunteers Register

Volunteers register through the Hare Krishna Visakhapatnam mobile app (and the harekrishnavizag.org website). Both post to the same POST /api/events/public/:eventId/register endpoint, so a volunteer who registers from the app is the same person in the admin panel as one who registered on the website — the phone number is their identity.

  • Events list (public site): https://vcc-client.vercel.app/events
  • My Seva (by phone): https://vcc-client.vercel.app/my-seva
